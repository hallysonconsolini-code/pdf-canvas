# Fonts

`Excalifont-*.woff2`: Excalifont by Excalidraw, licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org). Latin and Latin Extended subsets taken
from the `@excalidraw/excalidraw` 0.18.1 npm package.

`Excalifont-Latin.ttf` is the same Latin subset decompressed to TrueType, used
when embedding the font in exported PDFs.
